Petit script que je recopie d'un projet à l'autre : un thème monochrome,
sans boîte en haut et à droite, sans dégradés, avec une seule graisse pour
l'encre.

```python
import matplotlib.pyplot as plt

plt.rcParams.update(
    {
        "axes.spines.top": False,
        "axes.spines.right": False,
        "axes.edgecolor": "#e6e6e5",
        "axes.labelcolor": "#1a1a1a",
        "xtick.color": "#6b6b6b",
        "ytick.color": "#6b6b6b",
        "figure.facecolor": "white",
        "axes.facecolor": "white",
        "font.family": "serif",
        "font.size": 11,
    }
)
```

Le principe : une seule couleur (l'encre), des filets discrets, et laisser
le blanc structurer la figure. J'utilise le même principe sous R avec un
thème ggplot2 maison, pour que toutes les figures du site se ressemblent.
